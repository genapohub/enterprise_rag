## 1. 结论先行

**有条件通过（相对「换一家企业仍可用」）。**  
单组织本机可起 API、pytest 与上传问答冒烟能跑通，但换企业仍卡在：**成员只能靠 BOOTSTRAP 种子、邀请仅前端 UI+本地 501、无设密/建号接口；Compose Web 仍是 nginx 占位；默认 stub 下库外问题未稳定拒编**——需补成员入职路径与无命中口径后，才谈得上「另一家公司拿同一套就能用」。

上线口径（对交付说明）：**当前 P0 未清零 → 不上线**（阻塞见主表与专节）。

## 3.1 专节：成员邀请 / 账号密码（实测结论）

> 探活：API **8088 已起**（`/healthz` 200）；前端 **3080 未起**。故：后端用 curl 实测；前端邀请入口为**代码静态审查**（无法点浏览器），并写明未起服务。

### （1）前端有无「邀请/新增成员」入口？点了请求打到哪、状态码？

- **有入口（静态审查）**  
  - 路径：`06-项目编码/enterprise-rag-web/src/views/MembersView.vue`  
  - 管理员可见按钮文案「邀请成员」；弹层字段：账号 / 显示名 / 角色；提交调用 `api.inviteMember(...)`。  
- **请求实际去向（静态，未起 3080 故无浏览器 Network）**  
  - `src/api/index.ts` → 真后端实现 `src/api/client.ts` 的 `inviteMember`：  
    ```ts
    // client.ts:285-286
    export async function inviteMember(_body: InviteMemberRequest): Promise<Member> {
      throw new ApiError(501, '当前后端未开放邀请接口（契约：首期不做公开注册/邀请）')
    }
    ```  
  - **不会对 8088 发出 HTTP**；UI 捕获 `ApiError` 后在弹层展示错误文案（预期用户可见 501 语义消息）。  
- Mock 模式（`VITE_USE_MOCK=true`）下 `src/mock/api.ts` 另有本地 `inviteMember` 实现——**属 Mock，不得写成真链路已通**。

### （2）后端 OpenAPI/路由有无 create member / invite / set password？

**无接口（邀请创建与设密均无）。** 证据：

| 证据源 | 结论 |
| --- | --- |
| 路由 `app/routes/members.py` | 仅 `@router.get("")` → `GET /api/v1/members` |
| 全路由装饰器扫描 | members 无 POST/PATCH；auth 仅 login/refresh/me；**无** register / invite / set-password |
| OpenAPI `03-技术文档/企业RAG_openapi_v0.1.yaml` L485–503 | `/api/v1/members` **仅 get** `listMembers`；其后直接 `components:` |
| 契约 `企业RAG_API契约_v0.1.md` §3.6 | 列表 + 可选 PATCH role/is_active；正文：「**首期不做邀请/注册公开接口**；种子管理员由 `BOOTSTRAP_ADMIN_*`」 |
| 【实测 curl · 8088】登录后：`POST /api/v1/members` → **405** Method Not Allowed；`POST /api/v1/members/invite` → **404**；`PATCH /api/v1/members/fake-id` `{password}` → **404** |

账号密码现状：仅启动种子 `BOOTSTRAP_ADMIN_USER/PASSWORD`（`.env.example` 示例 `admin` / `changeme`）；**无**成员设密/重置 API。

### （3）结论一句话

**仅 UI**（仅 UI + 前端本地 501；后端无 invite/create/set-password 接口）。
