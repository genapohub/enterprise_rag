# 设计说明 · 企业 RAG 知识库关键页

## 1. 信息架构

```
登录
  → 知识库（默认落地）
       → 知识库详情 · 文档管理
  → 对话问答（独立入口，工具条选库）
  → 成员与角色
```

- **单组织**：无租户切换、无白标皮肤。
- **无机器人入口、无密级水印**（首期不做）。
- 品牌 VI/Logo 精稿不在本交付范围 → 侧栏使用中性色块 + 书本线框 SVG 占位标。

## 2. 视觉原则

- 中性企业后台：石墨侧栏 + 浅冷灰主区 + **单一青绿强调** `#0e7490`。
- 禁止：紫粉渐变、默认靛蓝 `#6366f1`、emoji 功能图标、Welcome/Lorem、假品牌名。
- 布局：桌面优先，侧栏约 220px + 主区；登录页左右分栏（窄屏收起品牌栏）。
- 实现预期：Vue3 组件可按壳（Sidebar/Topbar）+ 页面对齐本静态结构；状态用顶栏切换仅供设计审阅，上线后由真实数据驱动。

## 3. 权限差异（管理员 vs 成员）

| 能力 | 管理员 | 成员 |
| --- | --- | --- |
| 登录 | 有 | 有 |
| 知识库列表 / 新建 / 归档 | 有 | 只读列表（无新建按钮） |
| 文档上传 / 删除 / 重试索引 | 有 | 只读列表（无写操作） |
| 对话提问 / 看引用 | 有 | 有 |
| 成员邀请 / 改角色 / 停用 | 有 | 无（页面只读或入口隐藏，实现期二选一，建议入口隐藏） |

设计稿默认以**管理员视角**展示写操作；文档管理页脚有成员只读提示。对话页示例用户为成员「陈可」。

## 4. 关键状态矩阵

| 页面 | 默认 | 空 | 加载 | 错误 | 其它 |
| --- | --- | --- | --- | --- | --- |
| 登录 | 表单 | — | 登录中 | 账号密码错误 | — |
| 知识库列表 | 卡片网格 | 无库引导 | — | — | 新建弹层 |
| 文档管理 | 上传区+表 | 空库 | 骨架屏 | 列表失败 | 上传失败横幅、删除确认 |
| 对话 | 答案+引用 | 空会话建议问法 | 生成中三点 | 请求失败可重发 | **无命中**明确文案 |
| 成员 | 表格 | 仅自己时引导邀请 | — | — | 邀请弹层 |

## 5. 文案口径（产品）

- 无命中：**「知识库中未找到相关内容」**，并提示换库或请管理员补文档；声明不编造内部政策。
- 引用：至少展示文档名 + 片段；可点击进入文档管理（实现期可深链到原文位置）。
- 删除文档：说明后续问答不再引用；不回溯改写历史回答。

## 6. 给前端开工的提示

1. 先抽 `tokens.css` → 设计 Token / CSS 变量或 Uno/Tailwind theme 映射。
2. 壳组件：`AppSidebar`、`AppTopbar`、`EmptyState`、`Badge`、`DataTable`。
3. 对话：`CitationCard`、`Composer`、无命中块独立组件。
4. 本目录静态页**不得**当作功能验收通过；仅设计与实现对照。
