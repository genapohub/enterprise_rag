## 怎么打开审

1. 在 Finder 进入本目录，用浏览器直接打开任一 `*.html`（推荐 Chrome / Edge / Safari）。
2. 页面顶部有 **审阅状态** 切换条，可切换空态 / 有数据 / 加载 / 错误等，无需起服务。
3. 侧栏链接可在登录后页面之间跳转（静态相对路径）。
4. 样式依赖同目录 `tokens.css`，请保持相对路径，勿只拷单个 html。

```
05-UIUX设计/
  README.md
  设计说明.md
  tokens.css
  01-login.html
  02-kb-list.html
  03-kb-docs.html
  04-chat.html
  05-members.html
```

## Design Token 摘要

| 层 | 取值 |
| --- | --- |
| 中性 | 冷灰/石墨：`--color-bg #f4f6f8`、`--color-sidebar #1a1f26`、正文 `--color-text #1a1f26` |
| 强调 | 单一青绿 `--color-accent #0e7490`（**非**靛蓝 `#6366f1`，无紫粉渐变） |
| 语义 | 成功/警告/危险/信息各有 subtle 底 |
| 圆角 | sm 6 / md 8 / lg 12 / xl 16 |
| 字体 | Noto Sans SC / PingFang SC 体系；字重 400/510/590 |
| 规则 | 色值除 `#fff`/`#000` 外一律走 CSS 变量；图标为 SVG，无 emoji |

完整变量见 `tokens.css`。

## 导航结构（桌面优先）

```
登录（无壳）
 └─ 应用壳：左侧栏 + 顶栏 + 主区
      ├─ 知识库列表 → 文档管理
      ├─ 对话问答（选库）
      └─ 成员与角色（管理员写；成员只读口径见设计说明）
```

## 每页一句话交互

| 页 | 文件 | 一句话交互 |
| --- | --- | --- |
| 1 登录 | `01-login.html` | 输入本地账号密码登录；错误时字段标红并提示可联系管理员重置；登录中按钮禁用并显示进度。 |
| 2 知识库列表 | `02-kb-list.html` | 浏览/搜索知识库卡片，管理员点「新建」填名称创建；空态引导创建第一个库；点卡片进入文档管理。 |
| 3 文档管理 | `03-kb-docs.html` | 管理员拖拽或选择上传，列表展示解析/索引状态，失败可重试或删除；空库/加载/错误/上传失败/删除确认可审。 |
| 4 对话 | `04-chat.html` | 先选知识库再提问；有依据时答案下方出可点击引用卡片；无命中明确「知识库中未找到」；另可审生成中与请求错误。 |
| 5 成员与角色 | `05-members.html` | 管理员查看成员列表、邀请本地账号、改角色/停用；空列表引导邀请；成员无写操作（见设计说明）。 |
