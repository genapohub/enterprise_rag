# 企业 RAG 知识库 · 一页纸定位 v0.1

> 场景：0→1 新项目 · 拍板时间 2026-11-02 20:15 Asia/Shanghai  
> 首期：**单组织 Web 问答 MVP** · **设计先行（关键页设计稿）**  
> 栈默认：FastAPI + Vue3 + Docker Compose（向量库/嵌入模型待选型）

## 一句话

企业内部员工上传文档，用自然语言提问，答案必须带来源引用；管理员管知识库与成员。

## 用户与场景

| 角色 | 要做什么 | 成功长什么样 |
| --- | --- | --- |
| 管理员 | 建库、上传/下架文档、邀请成员、看索引状态 | 文档可查可删；失败有可读原因 |
| 普通成员 | 选库提问、追问、打开引用原文位置 | 有答案+引用；无命中时明确说找不到 |

## 首期必做（MVP）

1. 登录（本地账号即可，不做 SSO）
2. 知识库列表 / 新建 / 归档
3. 文档上传：PDF、Word（.docx）、Markdown、纯文本；显示解析/索引状态
4. 对话问答：流式或非流式均可；**每条答案至少 1 条可点击引用**（文档名+片段）
5. 权限：管理员 / 成员两级；成员只读问答+看自己库内文档列表
6. 本机 Docker Compose 一键起：API + Web + DB + 向量组件

## 首期不做

- 多租户 / 白标 / 计费
- 钉钉/企微/飞书机器人入口
- 复杂审批流、密级、水印、审计导出
- 图片 OCR、音视频转写、网页爬取入库
- 多模态视觉问答、Agent 工具调用编排
- 生产级 SSO（LDAP/OIDC）——二期再谈

## 关键页（设计稿范围）

1. 登录
2. 知识库列表（空态/有数据）
3. 知识库详情 · 文档管理（上传、状态、删除）
4. 对话页（提问、答案、引用侧栏/卡片、无结果）
5. 成员与角色（简单列表即可）

## 验收口径（首期过线）

- 上传 3 份样例文档后，对其中明确事实提问，答案能引用到对应片段
- 故意问库外问题，系统明确「知识库中未找到」类回复，不胡编当成事实
- 管理员可下架文档后，后续回答不再引用该文档
- `/healthz` 绿；Docker Compose 本机可起；前端可打开主路径上述 5 页
